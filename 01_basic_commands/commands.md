# Basic Linux Commands

## 1. pwd (Print Working Directory)

Shows current directory

Example:
pwd

Output:
/home/suman

---

## 2. ls (List files)

Lists files in directory

Example:
ls

ls -l # detailed list
ls -a # hidden files

---

## 3. cd (Change Directory)

cd folder_name # go inside folder
cd .. # go back
cd ~ # go to home
