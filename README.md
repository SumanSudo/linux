# Linux Learning Project 🐧

Welcome to the **Linux Learning Project**! This is a comprehensive guide designed to help you learn Linux from zero, progressing from fundamental concepts to advanced topics.

## About This Project

This project is a structured learning resource for anyone interested in mastering Linux. Whether you're a complete beginner or looking to deepen your Linux knowledge, you'll find organized materials, practical commands, and step-by-step guidance to build your expertise.

## How to Use This Project

1. **Start with basics** - Begin in `01_basic_commands/` and familiarize yourself with essential commands
2. **Practice regularly** - Type commands yourself; don't just read them
3. **Explore the filesystem** - Use your Linux system as a playground
4. **Read the documentation** - Use `man pages` to learn command details
5. **Build small projects** - Apply what you learn to real-world scenarios
6. **Progress gradually** - Move to intermediate topics once you're comfortable with basics

## Quick Start Guide

### Getting Started with Linux

#### Option 1: Use a Linux Distribution

- **Ubuntu** - Beginner-friendly
- **Fedora** - Latest technologies
- **CentOS** - Enterprise-focused
- **Debian** - Stable and reliable

#### Option 2: Windows Subsystem for Linux (WSL)

```bash
# Install WSL on Windows
wsl --install
```

#### Option 3: Virtual Machine

- Use VirtualBox or VMware to run Linux in a VM

### First Commands to Try

```bash
pwd              # Print working directory
ls               # List files
mkdir test       # Create a directory
cd test          # Change directory
touch file.txt   # Create a file
cat file.txt     # View file contents
```
